# Kailasa Temple 3D Experience

An immersive 3D web experience showcasing the architecture, history, and cultural significance of the Kailasa Temple at Ellora, Maharashtra, India.

## Live Demo

**Website:** https://kailasa-3d-experience.vercel.app/

## Overview

The Kailasa Temple 3D Experience brings one of India's most remarkable rock-cut monuments to the web through interactive 3D visualization, cinematic animations, and historical storytelling.

The project aims to provide an engaging digital exploration of the temple's architecture and heritage.

## Features

- Interactive 3D temple visualization
- Cinematic camera movements and scroll-based animations
- Historical storytelling across multiple chapters
- Interactive architectural hotspots
- Exploration of sculptures and architectural details
- Atmospheric lighting and visual effects
- Responsive web experience

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Three.js
- WebGL
- Vercel

## About the Monument

The Kailasa Temple is located at the Ellora Caves in Maharashtra, India. Renowned for its monumental rock-cut architecture and intricate stone carvings, it is one of the most extraordinary examples of Indian rock-cut architecture.

This project presents a digital interpretation of the monument, combining web technologies with interactive visual storytelling.

## Getting Started

To explore the project, visit the live website:

https://kailasa-3d-experience.vercel.app/

To run the project locally, clone the repository and open `index.html` in a local development server.
